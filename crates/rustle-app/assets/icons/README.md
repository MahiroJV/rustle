# Icons

- `material/` — from [Material Icon Theme](https://github.com/material-extensions/vscode-material-icon-theme), MIT license (see `material/LICENSE`).
  `folder.svg` and `file.svg` are Rustle's own: the theme generates these at build time,
  so we made them in the same style: the folder shape is from the theme's `folder-base.svg`, recolored to Rustle copper;
  the file shape is the "file" icon of [Material Design Icons](https://pictogrammers.com/library/mdi/) (Apache-2.0), in the theme's grey.
- `lucide/` — from [Lucide](https://github.com/lucide-icons/lucide), ISC license (see `lucide/LICENSE`).

To use your own icon, replace the SVG with the same file name.
